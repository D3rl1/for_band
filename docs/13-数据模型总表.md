# 13 · 数据模型总表（**全库唯一权威**）

> ## ⚠️ 这份文件是唯一权威
>
> 规格分散在 13 份文档里，**实现者很容易在 A 文档加了个字段、忘了在 B 文档同步**——
> 写规格阶段就已经踩过一次这个坑（`event` 合并之后，旧表还留在别的文档里，
> 导致同一份规格里有两套表结构）。
>
> **规则**：任何表结构改动，**先改这里，再改对应板块文档**。
> 落地前必须拿这份总表把所有文档对齐一遍。

**共 20 张表**——其中 **18 张在期 1 就要建**，另有 **2 张是预留**（`event_piece` 期 3 建、
`notification_log` 本项目不实现发送端）。

表名用 `snake_case`，字段用 `snake_case`（Java 实体用 camelCase，由 MyBatis-Plus 映射）。

### ④ `user_token` 登录令牌

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `id` | bigint | PK | |
| `token_hash` | varchar(64) | NOT NULL, **UNIQUE** | **只存哈希，不存原文** |
| `member_id` | bigint | NOT NULL, FK→member | |
| `issued_at` | datetime | NOT NULL | |
| `expires_at` | datetime | NOT NULL | 签发 + 30 天 |
| `revoked_at` | datetime | NULL | 非空即失效 |
| `user_agent` | varchar(255) | NULL | 登录时的 UA，**粗解析**成"设备"展示（解析粒度与"认不出来怎么办"见 `01-认证与账号.md` §1.4） |
| `ip` | varchar(45) | NULL | 登录 IP（IPv6 最长 45）。**存完整值**（审计用），**只有展示时打码**（见 `SECURITY.md` B9） |
| `last_seen_at` | datetime | NULL | **最后活跃时间**，用于"我在哪儿登录过" |

索引：`uk_token_hash`(UNIQUE) · `idx_member_id`

> **三条实现约定**（都影响这个表的用法）：
> 1. **多设备共存，不限制条数**：正常登录只签新行、**不撤销旧的**。
>    理由见 `01-认证与账号.md`「多设备与会话管理」。
> 2. **`last_seen_at` 粗粒度更新**：在鉴权拦截器里，该列**为 NULL 时立即写**（登录后第一个请求就会填上），
>    此后**距上次超过 1 小时才写一次**。否则每个 API 请求都会多一次 UPDATE（40 人量级虽扛得住，但没必要）。
> 3. **过期 / 已撤销的行不删**：它们就是**登录流水**（谁、何时、从哪个 IP 登过），留着有审计价值。
>    **"我的登录设备"列表只展示有效会话**（`revoked_at IS NULL` 且未过期）。

## 13.4 跨表的不变式（**实现时必须保证**）

| # | 不变式 | 违反后果 |
|---|---|---|
| 1 | `attendance` 的 `(event_id, member_id)` 唯一 | 重复签到、出勤率算错 |
| 2 | `member.account` 唯一 | 登录歧义 |
| 3 | `member.is_system=1` 的行**不出现在团员名单、不参与考勤统计** | 管理员被算进应到人数 |
| 4 | `member.status ≠ ACTIVE` ⇒ **禁止登录 + 作废其全部 token** | **安全漏洞**：退团的人还能看团里数据 |
| 5 | `event.section_id` 非空 **当且仅当** `kind = SECTION_CLASS` | 可见性判定出错 |
| 6 | 声部课的请假只生成 **1 条** `leave_approval`；排练生成 **2 条** | 审批流卡住或漏审 |
| 7 | 考勤出勤率按 **`joined_at` ~ `left_at`** 划边界计算；**声部课的应到名单还必须按 `event.date` 在 `member_role_history` 回溯"当时属于该声部"的人** | **出勤率算出 >100%**；以及**换过声部的人，其历史声部课两个声部都算错** |
| 8 | 变更角色时**必须**同时写 `member_role_history` | 历届成员页"历任职务"缺失 |
| 9 | 文件下载**必须鉴权**，磁盘文件名随机 | **权限模型形同虚设** |
| 10 | `operation_log` 只增不改不删 | 留痕失效 |
| 11 | 已取消（`CANCELED`）的活动**不可签到**，且统计时**整场排除** | 取消的场次还算人缺勤 |
| 12 | `event.start_time < event.end_time`，且**单场活动不跨天** | 签到窗口（`end + 2h`）在跨午夜活动上直接失效 |
