# 14 · 前端资源与样式规范

## 14.1 这个板块解决什么

管两件事：**第三方前端资源怎么放、怎么引**（这一节现在就能执行），
以及**界面视觉长什么样**（§14.6，待定稿）。

写这份的起因：2026-09-22 发现仓库里**并存两份 Bootstrap、版本还不一样**，页面引的是
没记录来源的那份；同时每个页面首屏会闪一下无样式白板。两个问题都源于"没有一份写下来的规矩"。

## 14.2 第三方前端资源：只有一个目录，一个库只存一份

**唯一目录**：`src/main/resources/static/vendor/<库名>/`

| 库 | 版本 | 文件 | 大小 | SHA256 |
|---|---|---|---|---|
| Bootstrap | **5.3.8** | `bootstrap/bootstrap.min.css` | 232,111 B | `d85327d99c7a3ee1f9b5d0500d1370acea3ad2db39c163c2f51f232baedbdede` |
| Bootstrap | **5.3.8** | `bootstrap/bootstrap.bundle.min.js` | 80,496 B | `e4fd49181388c48ec5040bd3fe66f57c29c8e67fcd8502b3354b96ec7ab47cc7` |

来源与升级步骤记在同目录的 `bootstrap/SOURCE.md`。

### 硬规矩

1. **一个库只存一份。** 仓库里出现第二份 = 将来必然有人改错那一份（本次踩的就是这个）。
2. **新增或升级任何第三方前端文件，必须**：三源下载 → **SHA256 一致才入库** →
   把版本号 / 来源 URL / SHA256 / 日期写进该目录的 `SOURCE.md`。
   **单一来源不许入库**——只从一个站下载等于无条件相信那一个站，文件被动过手脚是看不出来的。
3. **页面统一从本目录引入**，路径形如 `/vendor/bootstrap/…`。
4. **不许引外链（CDN）**。理由见 `DECISIONS.md` D7：校园网在未登录认证前会拦掉所有对外请求，
   样式取不到就是白板；且第三方 CDN 有投毒前科（BootCDN 2023-06 起，且专挑移动端下发）。

### 标准引入方式（每个页面 `<head>` 里照抄）

```html
<link rel="stylesheet" href="/vendor/bootstrap/bootstrap.min.css">
<script src="/vendor/bootstrap/bootstrap.bundle.min.js"></script>
```

`bundle` 版自带 Popper，弹窗 / 下拉都要它。

## 14.3 为什么 CSS 必须写在 `<head>` 里，不能用 JS 动态注入

浏览器拿到 HTML 后是**边解析边决定去下载什么**的。CSS 写在 `<head>` 里，浏览器一开始解析就知道
要去取样式，和 HTML 几乎同时到手，用户看到的就是完整页面。

**用 JS 在 `DOMContentLoaded` 里再 `document.createElement('link')` 挂样式，会出两个问题**：

1. **FOUC**（Flash of Unstyled Content，无样式内容闪烁）：页面已经渲染出来了、样式还没到，
   用户先看到一排没边框没颜色的黑字，然后"啪"地跳成正常样子。手机上网慢时更明显。
2. **同一份 JS 被加载两遍**：如果页面 `<head>` 里已经引了 `bootstrap.bundle.min.js`，
   脚本再动态插一个 `<script>`，就是加载并执行两次。Bootstrap 的 JS 负责往页面上挂下拉菜单、
   弹窗这些行为，挂两遍可能重复绑定（点一下菜单开两次）。

> **反例（已修）**：`static/app.js` 末尾曾在 `DOMContentLoaded` 里同时注入 `<link>` 和一个新的
> `<script>`，而各页面 `<head>` 又已经引了同一份 JS —— 于是每个页面首屏都闪，且 JS 跑两遍。

### 顺带发现的一个问题（属于期 1 代码，请一并处理）

实测时发现：**资源找不到时返回的是 500，而不是 404。**

```
GET /favicon.ico            → 500
GET /vendor/bootstrap.min.css（已删除的旧路径）→ 500
日志：c.forband.common.GlobalExceptionHandler : 系统异常
      org.springframework.web.servlet.resource.NoResourceFoundException: No static resource xxx
```

**为什么要紧**：浏览器**每次打开页面都会自动请求 `/favicon.ico`**，它不存在 → 于是
**每次页面加载都往日志里写一条 ERROR + 完整堆栈**。日志被这种噪音淹没后，真正的错误反而看不见
（项目自己的教训：最危险的 bug 都不报错、报错的反而要看得出）。浏览器控制台也会每次都有红色报错。

**该怎么改**：在 `GlobalExceptionHandler` 里把 `NoResourceFoundException` 映射为 **404**
（或明确放行 `/favicon.ico`）。「资源不存在」是客户端问题，不是服务端异常。

## 14.6 视觉规范（**已定稿**）

### 14.6.1 怎么用（实现者先读这段）

样式**只有一个入口**：

```html
<link rel="stylesheet" href="/vendor/bootstrap/bootstrap.min.css">
<link rel="stylesheet" href="/band.css">        <!-- 本规范的全部实现 -->
<script src="/band-nav.js"></script>            <!-- 深色侧栏的按键收起 -->
```

- **不要**在页面里写样式，**不要**用内联 `style=` 定颜色——一旦散开就改不动了。
- **改风格只改 `band.css` 的 §1「设计令牌」那一段**（全是 CSS 变量），别的地方都不用动。
- 页面骨架见 §14.6.4；一个完整的定稿样例在 `src/main/resources/static/design-samples/final-pc.html`。

> ⚠️ **自定义类名必须避开 Bootstrap 的保留类名。** 本项目已经栽过**四次**：
> `.row`（带 `flex-wrap` 的网格）、`.nav`、`.mark`（会给元素加黄色高亮背景）、`.btn`。
> 新增类名前，先去 `bootstrap.min.css` 里搜一下有没有同名。

### 14.6.2 色板：木与丝

取自**民乐器本体的材料色**——木（阮、琵琶、古筝、扬琴）与丝（弦）。

| 变量 | 值 | 用途 |
|---|---|---|
| `--silk` | `#F7F3EC` | 页面底（蚕丝米白） |
| `--cell` | `#F1EBE0` | 卡片 / 次级底 |
| `--pale` | `#D2C3AE` | 细线（**装饰性**，可以很淡） |
| `--edge` | `#9C856B` | 组件边界：输入框 / chip / 分页（要看得见，≥3:1） |
| `--wood` | `#7A5136` | **主色**：主按钮、选中、重点 |
| `--deep` | `#33241A` | 正文与标题 |
| `--mid` | `#6F5F51` | 次级文字 |
| `--shell` | `#2A1D14` | 深木：侧栏 / 主角格 |
| `--shellmid` | `#B3A392` | 深色底上的次级字 |
| `--shellhi` | `#C08A5E` | 深色底上的亮木（选中条等） |
| `--cinna` | `#B23A2E` | **朱砂**：只给异常状态与印章 |
| `--onwood` | `#FBF8F2` | 木色底上的字 |

**三条铁律：**

1. **不碰蓝系。** 学校**管乐团**系统的主色是靛蓝，两个团的系统要能一眼分开。
2. **朱砂只给"异常"和"印章"。** 休团 / 退团 / 毕业 / 警示 —— **常态（在团）不强调**，
   强调常态等于没有重点。印是朱砂的，因为**印本来就该是朱砂**。
3. **底色是暖中性白，不是宣纸黄。** （实测 `rgb(247,243,236)`，R−B 只有 +11；
   宣纸黄会在 +50 上下——一旦偏黄就滑向"古风文旅海报"。）

### 14.6.3 版式

- **少画框线，靠留白与字重分层。**
  一句话原则：**"如果你需要一条边框，你其实需要的是更多间距。"**
  → 侧栏没有底色边框、表格没有竖线网格、状态标记不带框。
- **间距与圆角全站统一**：`--gap: 20px`、`--radius: 14px`。格间距紧、格内边距松。
- **bento 只用于主页**，且遵守四条：
  **① 只有一个主角格**（两个大的会互相打架）；**② 尺寸种类 ≤ 3**（`2×2 / 2×1 / 1×1`）；
  **③ 每格 5 秒能讲完**（标题 + 一个值 + 一个视觉，需要一段话的就不是格子）；
  **④ 不画边框不加阴影**，靠色调与留白分隔。
  > 依据：眼球追踪显示人在大格子上的停留是等大格子的 **2.6 倍**——**尺寸即重要性**，
  > 它比颜色 / 字体 / 动效都更能定优先级。
- **密集数据仍然用表格**（bento 不适合密集表格）。

### 14.6.4 组件

**导航 = 深色侧栏 + 常驻把手，按键收起。**

- 默认**收起**（不占地方）；点左缘那个常驻**把手**展开；再点收起；`Esc` 收起；
  **选择存 `localStorage`**（用户下次打开还是他上次的样子）。
- **把手必须常驻**（任何时候看得见、点得到、`Tab` 得到）。它一次解决四件事：
  让人知道导航存在、消除"鼠标贴边落空"、当键盘入口、可点它切换。
- 把手是真 `<button>`，带 `aria-expanded` / `aria-label`。
- **不做"鼠标靠近自动弹出"**。实测数据不支持：NN/g 的实验显示隐藏导航在**桌面端**
  被漏掉的几率几乎翻倍；Vivaldi 7.9 上线同类功能后踩了"边缘空隙"和"与滚动条打架"两个坑。
- ⚠️ **收起状态类挂在 `<html>` 上，不是 `<body>`**（`html.nav-collapsed`）。
  原因：状态要在**首次绘制前**就应用好（否则会闪一下），而 `band-nav.js` 在 `<head>` 里加载，
  **那时 `document.body` 还是 `null`**——碰它会抛 `Cannot read properties of null`，
  把整个脚本打断，`window.bandNavInit` 永远赋不上值，**把手就点了没反应**。
  `<html>`（`documentElement`）在 `<head>` 阶段就已存在，所以状态放它身上既不会崩、也不闪。
  **这是真踩过的坑（2026-09-22），改这一块时别改回去。**
- ⚠️ **手机上（≤720px）不应用收起状态**：侧栏直接变成**顶部一条**横排、**常显**，把手隐藏。
  若在手机上沿用收起逻辑，会变成「侧栏 `display:none` + 把手也 `display:none`」——
  **首访用户没有任何导航入口**（这个 bug 真出过一次）。

**其余组件**（实现见 `band.css` 对应小节）。

> **`band.css` 里标注「实现期追加」的小节（如 `§7.5 表单控件与行内小件`）同属本规范**——
> 它们是实现过程中补的，不是"规格外的私货"。往 `band.css` 追加小节时可以，
> 但要**在 §14.6.8 速查表里登记一行**，否则下一个人不知道去哪儿改。

| 组件 | 规则 |
|---|---|
| 表格 `.tb` | 无竖线、无网格；只有表头下**一条细线**；行与行靠间距 |
| 状态 `.chip` | 常态只是次级色文字；**异常**才用朱砂 + 加粗 |
| 按钮 `.go` / `.go-ghost` | 主按钮实心木色；次级无边框描边 |
| 五声点阵 `.penta` | **点阵是主表达**：宫商角徵羽点亮几档。**旁边可以配精确数字**（`8 / 10` 或百分比），但**点阵必须在**——只有数字就退回成了普通后台 |
| 这周的谱 `.score` | 横轴是星期，块的高低 = 活动类型；**空白的日子写简谱的休止符「0」**（写在中线上）。**同一天有多场时取其类型最高的一档显示一块**（格子放不下多块，也不值得为它做堆叠） |
| 印章 `.stamp` | 签到的"签名动作"：印章落下 + 墨迹扩散，**朱砂色** |

### 14.6.5 字体

- **中文不上 webfont。** 中文字体单文件 5–20 MB，而我们无构建链 + 自托管 + 手机流量；
  且手机上各家的**系统中文黑体本来就是各平台最好看的那一档**。
- **中文界面的"个性"来自西文 / 数字字体、字重字号对比、排版结构、色彩** —— 不是中文字体。
- 西文与数字：**自托管 IBM Plex Sans 拉丁子集**（`static/fonts/plex/`，两个文件共 47 KB，OFL 授权）。
  用 `unicode-range` 把它的职责**钉死在拉丁与数字上**，中文必然落到系统字体。
- **中文字体栈必须列全**（否则华为 / 小米 / OPPO 手机会掉到默认 sans-serif）：
  `HarmonyOS Sans` / `MiSans` / `OPPO Sans` / `PingFang SC` / `Microsoft YaHei` / `Noto Sans CJK SC`，
  最后 `sans-serif` 兜底**不可省**。
- **中文只用 400 / 600**，不写 `500`（多数中文字体只有 400/700 两档，500 是浏览器**伪合成**、渲染发虚），
  也不写 `bold`。
- 行高 **1.7**（中文笔画密，比英文的 1.4–1.6 要松）；正文 `letter-spacing: 0`，**禁负字距**；
  **禁中文斜体**（无斜体字形，强制倾斜 = 把笔画拧歪），已用 `font-synthesis: weight` 关掉。
- 顺带一条文案规则：**盘古之白**——中英文 / 数字之间加空格。

### 14.6.6 动效与声音

**总原则：动效是沟通，不是装饰。每个动画都在回答一个用户没问出口的问题——做不到就砍掉。
装饰性动效是负债。惊喜来自具体，不来自装饰。**

- 时长：微交互 **150–250ms**、状态变化 200–300ms、页面切换 300–500ms（>500ms 显迟钝）。
- **只动 `transform` / `opacity` / `filter`**，绝不动 `width` / `height` / `left` / `top`
  （后者每帧触发布局重排，这是"顺滑还是卡顿"的分界）。
- **一次只动一个焦点**；列表逐个出现错开 **40ms**、**最多 5 个**。
- 不做 idle 浮动 / 呼吸 / 弹跳；**不使用弹跳缓动**；不打彩纸屑。
- **声音**：
  - 只挂在**"确认"类**动作上（签到成功等）；**不挂** hover / 滚动 / 导航（会变成噪音）；
  - **现场合成、零音频文件**（Web Audio）；全页**只有一个 `AudioContext`**；
    包络用**指数衰减**（线性到 0 会有爆音）；
  - 必须有**独立开关**（存 `localStorage`）+ **视觉等价物**（印章 + 文字）。
- **`prefers-reduced-motion` 必须降级**——是"减少"不是"删掉"：下落改成淡入，功能照旧。

| 某个组件的样式 | `band.css` 对应小节（§4 侧栏 / §6 bento / §7 按钮 / §7.5 表单小件 / §8 表格 / §9 乐团专属三样） |
| 前端资源怎么管 | 本文档 §14.2（自托管 + 记哈希 + 不引 CDN） |
| **改完前端怎么让它生效** | 跑仓库根的 **`./refresh.sh`**（构建资源 + 自动校验 `:8080` 与 `src/` 一致） |
