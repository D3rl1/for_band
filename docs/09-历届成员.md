## 9.1 这个板块解决什么

把**已经毕业**的团员留在这份档案里：他们当年在哪个声部、上过哪些台、担任过什么职务、
想对后辈说什么。让这个团的历史有地方沉淀。

---

## 9.2 数据模型

本板块**不新建主表**，数据来自三处：

| 来源 | 提供什么 |
|---|---|
| `member`（`03-团员与声部.md`） | 姓名、声部、在团年份（`joined_at` ~ `left_at`） |
| `concert_cast`（`07-演出.md`） | 参演过的演出 |
| `member_role_history`（`03-团员与声部.md`） | **历任职务**（曾任二胡声部长） |
| `concert_photo`（`07-演出.md`） | 演出合影 |

### 需要新增的字段

`member.alumni_message`（text NULL）——**本人寄语 / 一句话留言**。
毕业前（或毕业后）本人或管理员填写。

## 9.4 业务规则与边界

### 只列**毕业**的成员

| 状态 | 是否列入 |
|---|---|
| `GRADUATED` 毕业 | ✅ 列入 |
| `LEFT` 退团 | ❌ **不列入** |
| `PAUSED` 休团 | ❌ 不列入 |
| `ACTIVE` 在团 | ❌ 不列入（还在团里，不是"历届"） |

> **退团的不列入**：退团往往是个人的事（学业、身体、矛盾），公开列出来可能让当事人不舒服。
> 只有"毕业"是自然、体面的离团方式。

### 展示内容

| 项 | 来源 |
|---|---|
| 姓名 / 声部 / 在团年份 | `member` |
| 参演过的演出 | `concert_cast` |
| 演出合影 | 他**参演过的演出**所附带的照片（管理员可另指定一张代表作） |
| 本人寄语 | `member.alumni_message` |
| 历任职务 | `member_role_history`（"曾任二胡声部长"） |

### 排序方式：**按声部分组**

同一乐器的人排在一起，找师父方便。
