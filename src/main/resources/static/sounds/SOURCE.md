**生成方式**：`python tools/gen_metro_wavs.py`（可进仓库的正式脚本，从参数合成、不再缩放旧 WAV）。
包络与高精度模式 `BAND.tick()` 一一对应：`t=0` 为 0.0001 → `t+0.004s` 指数升到峰值 →
**保持到 `t+0.012s`**（8ms 保持段）→ `t+0.060s` 指数降到 0.0001 → `t+0.080s` 停声。
不归一化、不硬裁。

**哈希即基准**：两条文件的 SHA256 与用户点验通过的
`design-samples/metro-louder-study/proposed-{accent,weak}.wav` **逐字节一致**；脚本跑完会自己核对，
不一致直接失败（改参数必须重新点验，不能悄悄换声音）。

**响度**：80ms 窗 RMS 相对旧音 `+3.79dB`（重拍）/ `+4.11dB`（弱拍），由
`tools/metro_loudness_probe.py` 实测断言。
