如果这个图标是手机自带浏览器「添加到主屏幕」建的，录音和选文件可能用不了：请长按图标删除，改用上面的安卓 App（推荐）；或用 Chrome 打开本站重新安装。

安卓 App（推荐）

手机自带浏览器「添加到主屏幕」建的快捷方式可能无法录音或选文件；装这个 App 就都能用。

下载安卓 App

Android 8.0+ · 鸿蒙 4.x 及更早 · 不到 1 MB

首次安装若提示「未知来源」：小米在「设置 → 应用设置 → 授权管理 → 安装未知应用」允许浏览器；华为 / 荣耀在安装页点「继续安装」；OPPO / vivo 按提示允许本次安装。

首次打开要重新登录一次；以后覆盖安装升级，数据保留。

不想装 App？Android 用 Chrome / Edge

  1. 用 Chrome 或 Edge 打开本站（不要用手机自带浏览器、微信、QQ、夸克「添加到主屏幕」——那样建的快捷方式可能无法录音或选文件）。
  2. 点右上角 ⋮。
  3. 选「安装应用」或「添加到主屏幕」（不同版本措辞不同）。
  4. 确认。

鸿蒙 NEXT（5.x / 纯血）装不了安卓 App：请直接用 华为浏览器打开本站；鸿蒙专用版在做。

iPhone（必须用 Safari）

  1. 用 Safari 打开本站（iOS 上的 Chrome 不能添加到主屏幕）。
  2. 点底部「分享」按钮。
  3. 向下找到「添加到主屏幕」。
  4. 点「添加」。

iOS 14.3 及以上：添加到主屏幕后可以录音，录出来是 m4a。

iOS 的桌面网页应用有独立存储，装好后通常要重新登录一次；Android 一般保持登录。

微信 / QQ / 夸克等内置浏览器

这些内置浏览器不支持安装。

  1. 点右上角 ··· →「在浏览器打开」。
  2. 再按上面 Android / iPhone 的步骤做。

卸载与更新

长按桌面图标删除。新版本会自动提示，点「刷新」即可。
